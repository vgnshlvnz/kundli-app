# Nakshatra Tables — Jyotisha Reference

Scope: the 108 nakshatra padas with their rasi, lords, navamsa and purushartha; the attributes of the 27 nakshatras; and the meaning of each nakshatra's symbol.

Conventions used in this file:
- Pada numbers run 1–108 from Ashwini pada 1.
- Trigunas: R = Rajas, T = Tamas, S = Sattva.
- Yoni gender: (M) male, (F) female.
- "—" means the source gives no value.
- "Source note" marks places where the original sheet was inconsistent; nothing was silently corrected beyond spelling.
