# Tarabalam Table for Janma Nakshatra Pushya — Jyotisha Reference

Scope: worked Tarabalam (Nava Tara) table for a person whose Janma Nakshatra is Pushya, with the running pada count from Pushya.

Conventions used in this file:
- Counting starts from the Janma Nakshatra (Pushya = 1) and proceeds in zodiacal order through all 27 nakshatras.
- The nine taras repeat three times (three paryayas of nine nakshatras).
- Pada count: the four padas of Pushya are 1–4, and the count runs on to 108 at Punarvasu pada 4.
